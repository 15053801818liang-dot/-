## 运行指南

### ❶ 盘古

```bash
cd 盘古 && python3 pangu_v0.11.0.py          # REPL
python3 test_pangu_v0.10.0.py                 # 测试
```

### ❷ 缠论

```bash
python3 -m chanlun.demo                       # 演示
python3 chanlun/test_chanlun.py               # 测试
```

### ❸ Python 分布式调度器

```bash
pip install --break-system-packages -r requirements.txt
python3 -m pytest tests/test_distributed_scheduler.py
```

### ❹ Go DAG 调度器

```bash
python3 scripts/generate_btc_csv.py
WORKSPACE_DIR=workspace go run ./cmd/go-scheduler/
```

### ❺ C++ NeuralHub

```bash
cd distributed-scheduler
cmake -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build -j
./build/test_wal_replay && ./bench.sh 200 20000
```

### ❻ Claude API

```bash
pip install -r claude-api-example/requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...
python claude-api-example/chat.py "你好"
```
